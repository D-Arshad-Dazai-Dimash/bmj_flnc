# Тарифные пакеты

## Бизнес-правила

| Пакет | Диапазон | Комиссия | Технадзор |
|-------|----------|----------|-----------|
| 1 | до 100 000 ₸ | 600 ₸ фиксированная (добавляется к сумме) | Нет |
| 2 | 100 001–500 000 ₸ | 1% (добавляется к сумме) | Нет |
| 3 | от 500 001 ₸ | 10% ВКЛЮЧЕНА в сумму | Да |

## Хранение сумм

Все суммы хранятся в **тиынах** (1 тенге = 100 тиын) для точности.
Отображать пользователю в тенге (÷ 100).

## Распределение (Пакет 3)

- 90% — исполнителю
- 3% — технадзорщику
- 7% — платформе

## Утилита расчёта

`src/lib/pricing.ts`:

```typescript
import { calculateCommission, tengeToTiyn, tiynToTenge, formatTenge } from '@/lib/pricing'

const calc = calculateCommission(tengeToTiyn(500000))
// calc.package === 2
// calc.commissionTiyn === 500_000  (5 000 ₸)
// calc.totalFromClientTiyn === 50_500_000  (505 000 ₸)
```

## Поля в таблице `projects`

| Поле | Тип | Описание |
|------|-----|----------|
| package_tier | INT | 1, 2 или 3 |
| commission_amount | BIGINT | Комиссия в тиынах |
| total_amount | BIGINT | Итого с клиента в тиынах |
