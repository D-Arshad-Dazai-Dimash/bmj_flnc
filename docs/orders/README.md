# Заказы: фильтры, избранное, предложения

## Описание

Расширение раздела заказов: фильтрация, избранное, детальные предложения с сопроводительным письмом.

## Новые таблицы БД

### `favorites`

| Поле | Тип | Описание |
|------|-----|----------|
| id | UUID | PK |
| user_id | UUID | FK -> auth.users |
| project_id | UUID | FK -> projects |
| created_at | TIMESTAMPTZ | Дата добавления |

UNIQUE(user_id, project_id) — один проект в избранном один раз.

### Изменения в `project_applications`

- Добавлено поле `deadline_days` (INT, nullable) — предлагаемый срок в днях

## Фильтры

Доступные фильтры на странице ленты заказов:
- **Тип заказа** — выпадающий список (PROJECT, OUTSTAFF, AUDIT, SUPERVISION, CONSULTATION)
- **Мин/Макс бюджет** — числовые поля (₸)
- **Дата от / Дата до** — фильтр по дате публикации
- **Только избранные** — кнопка-переключатель

Фильтрация выполняется на клиенте (без дополнительных запросов к БД).

## Избранное

- Кнопка со звездой на каждой карточке заказа
- Оптимистичное обновление (мгновенный UI отклик)
- Данные сохраняются в таблице `favorites` через Supabase RLS

## Предложения

Два способа откликнуться:
1. **Быстрый отклик** — кнопка "Откликнуться" (как раньше)
2. **Детальное предложение** — кнопка "Подать предложение" открывает модальное окно:
   - Сопроводительное письмо (до 500 символов)
   - Предлагаемая цена (₸)
   - Предлагаемый срок (дней)

## Скрытие данных заказчика

API (Supabase select) возвращает только `full_name` и `avatar_url` заказчика. Email, phone и другие персональные данные не запрашиваются и не отображаются. RLS политики Supabase дополнительно ограничивают доступ.
